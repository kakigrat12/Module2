Набор лабораторных работ по Android-разработке на Java (лабы 1–8).

## Быстрый старт: поменять ФИО и цвет кнопок

В корне проекта лежит скрипт `customize.py`. Запустите его один раз — он обновит все лабы сразу.

```bash
# Случайный цвет из 10 заготовленных
python3 customize.py "Фамилия Имя Отчество"

# Конкретный цвет
python3 customize.py "Фамилия Имя Отчество" --color "#1E88E5"
```

Скрипт заменит ФИО во всех XML-макетах и `strings.xml`, добавит `button_color` в каждый `colors.xml` и проставит `app:backgroundTint="@color/button_color"` на все кнопки. После запуска просто пересоберите проект в Android Studio.

**Доступные цвета:**

| Hex | Цвет |
|-----|------|
| `#5C6BC0` | Indigo |
| `#7E57C2` | Deep Purple |
| `#26A69A` | Teal |
| `#1E88E5` | Blue |
| `#43A047` | Green |
| `#E91E8C` | Pink |
| `#F4511E` | Deep Orange |
| `#8E24AA` | Purple |
| `#00ACC1` | Cyan |
| `#FB8C00` | Orange |

## Лабораторные работы

### Лб 1 — Tween-анимация

Одна кнопка в центре экрана. По нажатию кнопка плавно увеличивается (`ScaleAnimation`), а TextView с ФИО внизу делает полный оборот (`RotateAnimation`). Анимации описаны в XML-файлах в `res/anim/`.

---

### Лб 2 — Карты (OpenStreetMap)

Интерактивная карта на базе библиотеки **osmdroid** (тайлы OpenStreetMap / Mapnik). При старте центрируется на Москве. Запрашивает разрешение `ACCESS_FINE_LOCATION`, после получения подписывается на GPS-обновления и перемещает карту к текущей позиции, ставя маркер «Я здесь».

---

### Лб 3 — App Widget с настройкой

Виджет для домашнего экрана с кнопкой «Открыть сайт». При добавлении виджета открывается экран конфигурации (`NewAppWidgetConfigureActivity`), где пользователь вводит URL. URL сохраняется в `SharedPreferences`; нажатие на виджет открывает указанный адрес в браузере.

---

### Лб 4 — Меню (Options + Context)

Поле ввода текста с двумя видами меню:
- **Options menu** — пункты «Показать подсказку» (чекбокс), «Очистить», «О программе».
- **Context menu** (долгое нажатие на поле) — «Очистить поле», «В верхний регистр», «В нижний регистр».

«О программе» показывает `AlertDialog` с именем и номером лабы.

---

### Лб 5 — Диалоговое окно

Кнопка «Выход» в центре экрана. Нажатие открывает `AlertDialog` с вопросом «Вы действительно хотите выйти?» и кнопками «Да» / «Нет». «Да» завершает активити, «Нет» закрывает диалог.

---

### Лб 6 — Уведомления со звуком

Кнопка «Отправить уведомление». По нажатию создаётся `NotificationChannel` (если ещё нет) и отправляется уведомление со стандартным звуком системы (`RingtoneManager.TYPE_NOTIFICATION`). На Android 13+ запрашивает разрешение `POST_NOTIFICATIONS`. Меню «О программе» — `AlertDialog`.

---

### Лб 7 — Воспроизведение аудио

Кнопка «Воспроизвести звук». По нажатию `MediaPlayer` проигрывает аудиофайл из `res/raw/`, параллельно внизу экрана появляется `Snackbar` «Воспроизводится звук». Меню «О программе» — `AlertDialog`.

---

### Лб 8 — SharedPreferences + SQLite

Поле ввода и две кнопки:
- **Добавить в БД** — сохраняет введённый текст в SQLite (через `DatabaseHelper`).
- **Показать записи** — выводит все строки из базы в `TextView`.

В меню — «Настройки» (открывает `SettingsActivity` на основе `PreferenceFragmentCompat`) и «О программе».
